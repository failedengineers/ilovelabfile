PDF text editor built for GGSIPU & DTU practical files

PDFShift is a free online PDF text editor for targeted corrections. Students at GGSIPU — Guru Gobind Singh Indraprastha University and DTU — Delhi Technological University use it to change a name in a PDF, replace an enrollment number, update a roll number, correct a registration ID or fix a course code across an entire lab file, practical file or workshop file — without retyping or reformatting the document.

The processing is deliberately simple to reason about: for each Find → Replace pair, PDFShift searches the PDF page by page and changes only the first matching occurrence on each page. That keeps results predictable on documents where the same student detail repeats on every page, which is the normal shape of a GGSIPU or DTU B.Tech practical file.

Does PDFShift replace every occurrence on a page?

No. The current behavior replaces only the first matching occurrence on each individual page.

Can I use this for a GGSIPU or DTU practical file?

Yes — it's commonly used to change a name, enrollment number or roll number that repeats on every page of a GGSIPU or DTU lab file, practical file or workshop file.

What if the same text appears once on several pages?

The first match on each page can be changed, so the same Find value may be replaced once on page 1, once on page 2, and so on.

Can I make multiple changes in one PDF?

Yes. Add multiple Find → Replace pairs before submitting the document.
