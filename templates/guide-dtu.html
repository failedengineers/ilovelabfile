How to edit your name and roll number in a DTU lab file PDF

DTU lab files and practical files usually repeat your name and roll number on every page — which makes manually fixing a typo painful. This walks through doing it once, for the whole file, in one pass.

  1. Note the exact text to change — Check your lab file for exactly how your name or roll number is printed — capitalisation and spacing matter for an exact match.
  2. Upload your PDF — Head to the iLoveLabFile editor and upload your lab file, practical file or workshop file PDF.
  3. Add a Find → Replace pair for each change — Add one row for the name, another for the roll number if both need fixing — you can stack as many pairs as you need.
  4. Run it and check both versions — Hit Correct PDF, then use the Original / Corrected tabs to check the change looks right before downloading.
  5. Download the corrected file — Save the corrected PDF — ready to submit, with the rest of the document untouched.

Remember the page rule

iLoveLabFile changes the first matching occurrence on each page — not every occurrence in the whole PDF. If the same text repeats twice on one page, only the first copy on that page updates.

Formatting, tables and diagrams stay untouched — only the text you target changes.

FAQ

Can I fix a name and a roll number at the same time?

Yes — add a separate Find → Replace row for each. Both are applied in the same pass over the PDF.

Does it work on scanned/image-only lab files?

No — this only works on PDFs where the text is selectable (not a scanned image). Most college-generated lab files and Word-to-PDF exports are text-based, so this covers the common case.

Is my file uploaded anywhere permanently?

The tool processes your file to generate the corrected version and doesn't require you to create an account to use it.
