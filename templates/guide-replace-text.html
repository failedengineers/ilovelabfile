How to replace text in a college PDF — without reprinting the whole thing

Lab files, practical files, assignments and workshop files almost always repeat the same student details across every page — a name, a roll number, a batch code, a course title. If just one of those is wrong, you shouldn't have to regenerate the whole document. Here's the general approach.

  1. Identify what needs to change — It could be a name, enrollment number, roll number, section, batch, course code — anything printed as text (not part of a scanned image).
  2. Copy the exact current text — Match it exactly, including spacing and case, from the PDF itself rather than typing from memory.
  3. Upload to iLoveLabFile — Drop your PDF into the editor — works for lab files, practical files, assignments and workshop files alike.
  4. Set up your Find → Replace pairs — Add one pair per piece of text you're correcting. You can queue up several changes before processing.
  5. Compare before you download — Use the Original vs Corrected preview to confirm every page updated the way you expected, then download.

Remember the page rule

iLoveLabFile changes the first matching occurrence on each page — not every occurrence in the whole PDF. If the same text repeats twice on one page, only the first copy on that page updates.

Formatting, tables and diagrams stay untouched — only the text you target changes.

FAQ

Does this work for any college, not just GGSIPU or DTU?

Yes — the tool works on any text-based PDF. GGSIPU and DTU are common examples because their practical file format repeats student details on every page, but the same approach works for any university's documents.

What's the 'first match per page' rule?

For each Find → Replace pair, only the first occurrence of the old text on each individual page is changed — not every occurrence across the whole document. This keeps results predictable when the same text shows up more than once on a page.
