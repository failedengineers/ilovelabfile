Copied a friend's lab file? Here's how to fix the name before you print

It happens every semester — you copy a senior's or friend's lab file as a template, forget to swap the name and enrollment number on every page, and only notice at the printout counter. Here's the fast fix, no retyping required.

  1. Don't panic-edit it page by page — Opening the PDF and manually retyping the name on 20-40 pages is exactly the slow way to do this — skip it.
  2. Upload the copied file to iLoveLabFile — Go to the editor and upload the PDF exactly as it is, with your friend's details still in it.
  3. Find their name, Replace with yours — In Find, paste their name exactly as printed. In Replace, type your own name. Add a second row for the enrollment/roll number the same way.
  4. Run it and check the preview — Hit Correct PDF, then flip through Original vs Corrected to confirm every page now shows your details, not theirs.
  5. Download — ready to print — The corrected file keeps their original formatting, code, diagrams and tables exactly as they were — only the identity details change.

Remember the page rule

iLoveLabFile changes the first matching occurrence on each page — not every occurrence in the whole PDF. If the same text repeats twice on one page, only the first copy on that page updates.

Formatting, tables and diagrams stay untouched — only the text you target changes.

FAQ

Will this also fix their roll number or section if it's in there too?

Yes — add a separate Find/Replace row for each detail that needs swapping (name, enrollment number, roll number, batch), and all of them get corrected in the same pass.

What if their name appears differently on different pages (e.g. with vs without middle name)?

Add one Find/Replace pair for each exact variation you spot. The tool matches exact text, so slightly different spellings need their own row.

Is this okay to do, academically?

Using a friend's file as a formatting/structure template and correcting the identity details to your own is normal practice — this tool just makes that correction step faster and less error-prone than doing it by hand.
